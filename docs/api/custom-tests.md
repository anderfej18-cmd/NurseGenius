# Live tests (shared tests)

Source: `src/functions/custom-tests.functions.ts` → `src/server/custom-tests/`. Admin-built, scheduled tests that anyone
with the link can take. ADR-0009 (layers), ADR-0012 (schedule, server clock, privacy). Strict schemas everywhere
(`src/functions/custom-tests.schemas.ts`). Every moment that matters is the database's `now()`.

## Admin functions (`POST`, admin only; 403 otherwise)

| Function                    | Request                                                                                                                                                                                         | Response                                                                                                                                         | Rules                                                                                                                                                                                                                                                                                                    |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `createCustomTest`          | `{ title ≤200, description ≤2000, examType, sourceMode: "existing"\|"upload", durationMinutes 10–180, startsAt, expiresAt, allocations: [{ topic, count }] (bank), questions[1–250] (upload) }` | `{ id, token }`                                                                                                                                  | Window 10 minutes to 90 days, ending in the future. Bank: the database draws `count` random active, complete questions per subcategory, 400 naming the subcategory when a count exceeds its pool, at most 250 in total. The link is made on the server. The questions are copied into the test. Audited. |
| `listCustomTests`           | `{}`                                                                                                                                                                                            | each test the caller manages (all tests for the central admin) with `state` (upcoming, live, closed), `share_token`, `analytics`, and `attempts` | Pass mark 50%. `attempts` (final ranking) are returned only for closed tests; emails are masked for anyone but the central admin. Unsubmitted attempts past their time are closed and scored on read.                                                                                                    |
| `republishCustomTest`       | `{ testId, startsAt, expiresAt, durationMinutes }`                                                                                                                                              | `{ token }`                                                                                                                                      | New link and schedule; the old link stops working. Owner or central admin, else 404. Audited.                                                                                                                                                                                                            |
| `importCustomTestQuestions` | `{ testId, examType, topic }`                                                                                                                                                                   | `{ added, skipped }`                                                                                                                             | Copies only uploaded questions, once, into the chosen exam type and subcategory; skips text the bank already has (ignoring case and spacing). Owner or central admin. Audited.                                                                                                                           |

## Public functions (`POST`, no sign-in; the link token and the attempt key are the credentials)

| Function           | Request                                                                             | Response                                                                    | Rules and errors                                                                                                                                                                                                                           |
| ------------------ | ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `getSharedTest`    | `{ tokenHash }`                                                                     | `{ state, serverNow, test }`                                                | `state` is upcoming, live or closed by the database clock. **No questions.** 60 views a minute per address.                                                                                                                                |
| `startSharedTest`  | `{ tokenHash, email, accessKey (32–256) }`                                          | `{ attemptId, attempt }`                                                    | Only inside the window (409 not started, 404 closed). 20 starts an hour per address and 5 a day per email and test, else 429. Only the SHA-256 of the key is stored.                                                                       |
| `getSharedAttempt` | `{ attemptId, accessKey }`                                                          | the attempt: questions (no key) with saved answers and flags, or its result | Resume after a reload. An attempt past its deadline is closed here from its saved answers. 120 a minute per address.                                                                                                                       |
| `saveSharedAnswer` | `{ attemptId, accessKey, questionId, answer: A–D\|null, flagged }`                  | `{ saved: true }`                                                           | Stored as chosen. 409 after the attempt's deadline (plus 15 seconds). 3000 saves an hour per attempt.                                                                                                                                      |
| `submitSharedTest` | `{ attemptId, accessKey, answers: [{ question_id, user_answer: A–D\|null }] ≤250 }` | `{ score, correct, total, results[] }`                                      | Scored in the database from the stored key. Before the deadline the submitted answers count and at least 80% must be answered; after it only saved answers count. 409 if already submitted, 404 wrong key. 30 submits an hour per address. |

## Signed-in student

| Function                 | Request                    | Response               | Rules                                                                                                                                                                                                     |
| ------------------------ | -------------------------- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `claimSharedTestAttempt` | `{ attemptId, accessKey }` | `{ claimed: boolean }` | Needs the attempt key, an account email the identity provider has **confirmed**, and that address equal to the one the test was taken with: 403 otherwise. `claimed: false` if linked to another account. |

Ask AI works on a shared attempt only after it is linked to an account. Errors never contain database text:
unexpected failures answer `Something went wrong. Please try again.`
